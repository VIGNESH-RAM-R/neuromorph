This page needs to run through a dev server, not be opened directly.

You opened this file with a double-click (the address bar shows file://...). React/Vite apps can't run that way -- browsers can't parse JSX or resolve the module imports over the file protocol. Open a terminal in this folder and run: 

npm install
npm run dev

Then open the local address it prints (usually http://localhost:5174). See README.md for full VS Code steps.
